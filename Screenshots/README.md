# 🏡 House Price Prediction System

An end-to-end Machine Learning web application designed to predict residential property prices based on key features such as area, number of bedrooms, and building age. The project covers the complete workflow from raw dataset processing to model training, evaluation, saving, and deployment via a Streamlit web interface.
